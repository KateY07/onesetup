    小工具，成品感

    安装器该有的都有，而且不需要你另外带任何东西。

    单文件输出

    安装包解压到临时目录，在其中运行 install.bat，结束后自行清理。

    7-Zip 压缩

    LZMA2，-l 0–9 可调：已压缩的数据用 0，要最小体积用 9。

    原生界面外壳

    --ui 附带约 220 KB 的 Win32 + Direct2D 窗口，Acrylic 毛玻璃，目标机无需 .NET。

    用输出控制界面

    install.bat 里 echo 一行 .info、.progress、.ask 即可，没有 SDK，没有 API。

    启动的程序不受牵连

    用 start 启动的应用在安装窗口关闭后继续运行，窗口也不会等它。

    仓库只含源码

    界面外壳在每次构建时由 ui/native 用 MSVC 编译并内嵌，仓库里没有二进制。

    快速开始

    下载 onesetup.exe，指向一个目录，把生成的文件发出去。

    # pack ./app → setup.exe
onesetup app -o setup.exe

# with the progress window
onesetup app --ui -o setup.exe

# smaller / faster (0 = store, 9 = smallest)
onesetup app -l 5

# silent run of the result
setup.exe -y
    -o, --output输出文件，默认 <目录>_setup.exe，不会覆盖已有文件。
    -l, --level压缩等级 0–9，默认 9。
    --ui通过内置界面外壳运行 install.bat（需要 install.bat）。
    --ui-exe同上，使用自定义的 onesetup-ui.exe。
    -h, --help完整用法、示例与退出码。

    让脚本驱动窗口

    以点开头的行是指令，其余输出进入“详情”日志。

    @echo off
echo .title My App
echo .info Copying files
echo .progress 40
xcopy /E /I app "%LOCALAPPDATA%\MyApp" >nul

echo .ask Launch My App now?
set /p ANS=
if /i "%ANS%"=="yes" start "" "%LOCALAPPDATA%\MyApp\app.exe"

echo .progress 100
echo .info Done
    .title窗口标题
    .info清单里的新步骤
    .warn / .error琥珀色 / 红色条目
    .progress 0-100进度条
    .ask是/否抽屉，答案从 stdin 传回
    (other)进入“详情”日志

    须知

    把边界说清楚，免得上线时意外。

    安装包退出码恒为 07zSD 模块不传递 install.bat 的退出码。窗口会显示失败；自动化场景请让 install.bat 自己写日志或标记文件。
    install.bat 保持 ASCIIcmd 可能截断跨过 512 字节读取块的 UTF-8 行。把本地化文字放进 UTF-8 文件，用 type 输出。
    毛玻璃需要较新的 Windows当前版本的 Windows 10 / 11 支持 Acrylic；不可用时自动回退为白色卡片。
