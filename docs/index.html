    Small tool, finished feel

    Everything an installer needs, nothing you have to ship alongside it.

    One file out

    The package extracts to a temp folder, runs install.bat there, then cleans up after itself.

    7-Zip compression

    LZMA2 with -l 0–9: store for already-compressed data, 9 for the smallest installer.

    Native UI shell

    --ui adds a ~220 KB Win32 + Direct2D window with Acrylic glass. No .NET to install on the target.

    Scripted by stdout

    Your install.bat just echoes ".info", ".progress", ".ask" lines. No SDK, no API.

    Launch survives

    An app started with "start" keeps running after the installer closes, and the window never waits for it.

    Source only, built fresh

    The UI shell is compiled from ui/native with MSVC on every build and embedded. No binary blobs in git.

    Quick start

    Download onesetup.exe, point it at a folder, ship the result.

    # pack ./app → setup.exe
onesetup app -o setup.exe

# with the progress window
onesetup app --ui -o setup.exe

# smaller / faster (0 = store, 9 = smallest)
onesetup app -l 5

# silent run of the result
setup.exe -y
    -o, --outputOutput file. Default: <dir>_setup.exe. Never overwrites.
    -l, --levelCompression 0–9, default 9.
    --uiRun install.bat through the built-in UI shell (needs install.bat).
    --ui-exeSame, with your own onesetup-ui.exe.
    -h, --helpFull usage, examples and exit codes.

    Your script drives the window

    Lines starting with a dot are commands; everything else lands in the Details log.

    @echo off
echo .title My App
echo .info Copying files
echo .progress 40
xcopy /E /I app "%LOCALAPPDATA%\MyApp" >nul

echo .ask Launch My App now?
set /p ANS=
if /i "%ANS%"=="yes" start "" "%LOCALAPPDATA%\MyApp\app.exe"

echo .progress 100
echo .info Done
    .titleWindow heading
    .infoNew step in the checklist
    .warn / .errorAmber / red row
    .progress 0-100Progress bar
    .askYes/No sheet; the answer arrives on stdin
    (other)Kept in the Details log

    Good to know

    Honest edges, so nothing surprises you in production.

    Exit code is always 0The 7zSD module does not pass install.bat's exit code on. The window shows failures; for automation have install.bat write a log or marker file.
    Keep install.bat ASCIIcmd can cut a UTF-8 line that crosses its 512-byte read block. Put localized text in a UTF-8 file and print it with "type".
    Glass needs a modern WindowsAcrylic works on current Windows 10 / 11; if unavailable the window falls back to a clean white card.
